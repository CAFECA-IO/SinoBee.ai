Card network marks shown by the card pickers (`src/components/card-brand.tsx`).

Put each network's official acceptance mark here as `<brand>.svg` — `visa.svg`, `mastercard.svg`, `jcb.svg`,
`amex.svg`, `unionpay.svg`, `diners.svg`, `discover.svg` — downloaded from that network's brand centre and used as
its guidelines allow. A missing file falls back to a neutral card with the network's name.
