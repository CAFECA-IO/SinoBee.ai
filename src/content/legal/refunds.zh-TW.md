## 1. 七日解除權

本服務為線上提供的數位服務，於您付款並同意後立即開始提供。依《通訊交易解除權合理例外情事適用準則》第 2 條，這類服務不適用《消費者保護法》第 19 條的七日無條件解除權。但我們仍依下列條件提供退款。

## 2. 訂閱方案

| 情況 | 退款 |
| --- | --- |
| 付款後 7 天內，且該期尚未開始（預先購買、接在現有期間之後的那一期） | 全額退款 |
| 付款後 7 天內，該期已開始但尚未使用任何訂閱額度 | 全額退款 |
| 該期已開始且已使用額度 | 原則上不退款，也不按天數比例退款 |
| 可歸責於本公司的服務異常，導致該期無法正常使用 | 依影響期間或額度比例退款 |

- 訂閱期間退款後，該期立即取消；之後已預先購買的期間會往前遞補。
- 不自動續訂，因此不會有未經同意的續訂扣款。

## 3. 眾籌任務與模型評鑑

| 情況 | 處理方式 |
| --- | --- |
| 眾籌提案費 | 不可退還；已換算為規格對話的 Token 與參考檔案的儲存空間。眾籌達標時未用完的部分併入任務預算 |
| 眾籌期間撤回出資，或眾籌未達標 | 信用卡不會被扣款；以點數或訂閱額度出資者，原數退回點數或額度 |
| 達標後請款期間實收不足目標 | 已扣款的信用卡全額退刷，點數與額度原數退回 |
| 任務完成、結案或失敗後仍有未使用的經費 | 依出資比例轉為平台點數（以訂閱額度出資的部分退回額度），不退還現金 |
| 驗收爭議經平台判定成果不符規格 | 全部經費（含已使用部分）依出資比例轉為平台點數 |
| 因平台錯誤導致任務失敗 | 預設補發平台點數；出資者可申請改為退回原付款方式 |

- 平台點數：1 點等於新臺幣 1 元，只能用於眾籌出資，不可轉讓、不能兌換現金，沒有使用期限。帳號終止或本服務停止時，未使用的點數依法令處理。
- 規格在眾籌期間修訂時，修訂後 72 小時內不會請款，不同意的出資者可以撤回出資。

## 5. 退款方式與時間

1. 退款一律退回原付款方式，由付款服務商應援科技股份有限公司（Oen，[https://oen.tw/](https://oen.tw/)）辦理：
   - 本服務僅接受以 Oen 綁定的信用卡付款，退款一律退刷至原卡；實際入帳時間依發卡銀行作業，通常需 7 至 14 個工作天。
2. 依 Oen 的規定，**每筆付款只能退款一次**。部分退款後，剩餘金額不能再申請退款。
3. 已開立的電子發票，Oen 會開立相應的折讓單。

- 違反[服務條款](/terms)（例如共用帳號、規避額度或濫用）而遭暫停或終止。
- 已使用的服務或已收取的用量費用，但第 2、3 節另有規定者除外。
